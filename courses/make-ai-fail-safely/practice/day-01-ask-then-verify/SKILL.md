# Ask, then verify

**Confident wrongness** is a false claim in the same calm voice as a true one. Fix it in two moves: **ask** so the answer is more likely correct or clearly UNKNOWN, then **verify**. Better asking cuts fiction; verification still decides what ships.

Paste Part A into any chat. Do Part B yourself. Swap brackets. Tighten or drop rules if you need to.

## Part A — Ask (paste / adapt)

```
Answer this question: [YOUR QUESTION]

Rules:
1. Label each claim FACT or GUESS.
2. For every FACT, include a real source: a working URL, or the exact document title and where to look (section / page / heading).
3. If you cannot cite a real source, write UNKNOWN for that claim. Do not invent links, titles, names, dates, or numbers.
4. Prefer a quoted line or a URL over a vague summary.
```

**Optional tighteners:** ask for a checkable pointer ("Quote the line / give the URL that states X") instead of an open "what's the date of Y." Treat unlabeled "facts" as guesses until Part B.

## Part B — Verify (you do this)

1. **Open the citation.** Click the link or find the named doc. No citation, invented link/title, or UNKNOWN → do not paste the claim; stop or look yourself.
2. **Draft vs verified.** Keep the reply as a **draft**. Ship only a **verified** version after at least one real check. Same window is fine; two buckets are not optional.
3. **Optional:** After you score the draft (finished / detailed / correct-as-you-know), run one independent check (search or a second model). For claims that matter, name what would prove it wrong before you use it.

**Done when:** you either opened a real source and decided paste-ready / not, or you correctly stopped on UNKNOWN.
