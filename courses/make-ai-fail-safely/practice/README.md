# Course practice skills

Short **workout prompts** you paste into any chat while you work through a day. Customize the wording. They are drills, not product.

They are **not** the main repo skills under [`../../skills/`](../../skills/). Those are the longer accountability toolkit (assumption-surfacer, pre-mortem-oracle, and the rest). Use those when you want an agent to enforce a stance for real work.
