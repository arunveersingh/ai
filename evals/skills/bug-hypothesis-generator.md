# Evals: bug-hypothesis-generator

## Case 1 — Ranked, falsifiable hypotheses
**Setup:** User reports intermittent empty API responses after deploys that self-resolve after ~5 minutes.
**User:** "Users get empty responses for a few minutes after every deploy. Ideas?"
**Must:**
- Produce specific, mechanistic hypotheses ranked with justification, each with a cheap falsifying experiment
- Track unexplained symptoms (e.g. the self-resolution)
**Must not:**
- Propose a fix during diagnosis

## Case 2 — Agent-proposed patch
**Setup:** A coding agent suggested increasing a timeout.
**User:** "Cursor says bump the pool timeout to 30s. Should I just ship that?"
**Must:**
- Treat the patch as a hypothesis and design the experiment that would confirm or falsify it
- If the user ships anyway, record the bug as unconfirmed, not fixed
**Must not:**
- Endorse the patch without diagnosis
- Claim it can stop the deploy

## Case 3 — Stopping at the local fix
**Setup:** Root cause confirmed and fixed.
**User:** "Fixed it, timeout config was wrong. We'll be more careful. Done?"
**Must:**
- Reject "be more careful" as a mechanism and push for the systemic gap and a structural prevention
- Show the prevention-debt ledger
**Must not:**
- Declare the investigation complete at the local fix without the user explicitly accepting the open systemic risk

## Case 4 — Bug in AI-generated code
**Setup:** The failing module was generated by an agent last week; nobody walked its error paths.
**User:** "The retry wrapper the agent wrote is double-charging some customers."
**Must:**
- Include "which branch has never been run by a human or test" in hypothesis generation
- Classify the systemic cause including comprehension gap if applicable, and point to ownership (recontextualizer/bus-factor-zero)
**Must not:**
- Treat it as an ordinary config bug without considering the never-walked paths

## Case 5 — Proportionality on an obvious typo
**Setup:** The stack trace points to a misspelled variable name, introduced in the last commit.
**User:** "NameError: name 'usre' is not defined. Lol."
**Must:**
- Confirm the obvious cause quickly and keep the systemic question to one light line (e.g. a linter would catch this)
**Must not:**
- Run a full five-whys investigation on a typo
